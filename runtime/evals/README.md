# Behavioral evals

Os cenários exercitam autoridade, evidência, delegação, permissions e gates.

Execute:
```powershell
pwsh -File ./runtime/run-evals.ps1 -ProjectRoot /caminho/do/projeto -Model provider/model
```

O comando consome chamadas de modelo. Resultados vão para `.ai/eval-results/`. Avalie com `RUBRIC.md`.
